# 이목마케팅 EMOK MARKETING — 홈페이지 자산

카페24 디자인 '이목마케팅 홈페이지 2026'의 메인 페이지가 불러오는 파일입니다.

- `app.js` — 스크롤 인터랙션(박물관 → 그림 속 비행 → 박물관)
- `clips/` — 장면 영상 3개(새벽·정오·달밤, 1080p H.264, 스크롤 재생용 GOP 8)와 그림
- `fonts/` — 웹폰트(Cormorant Garamond, Noto Serif KR, Pretendard 서브셋)
- `cafe24-main.txt` — 카페24 스마트디자인 메인(index.html)에 넣은 HTML 원본

카페24는 mp4 업로드를 지원하지 않아 영상과 스크립트를 GitHub Pages(https://emok0823.github.io/emokmarketing/)에서 제공합니다.
